# Contributing to Claude Optimization System

## Comment Contribuer

### Types de Contributions Recherchées

1. **Nouveaux Templates**
   - Optimisés (< 300 tokens)
   - Testés (avec métriques)
   - Documentés (cas d'usage)

2. **Exemples Concrets**
   - Avant/Après avec métriques
   - Cas réels (anonymisés)

3. **Benchmarks & Métriques**
   - Résultats mesurés
   - Comparaisons

4. **Patterns Émergents**
   - Nouvelles découvertes
   - Optimisations avancées

### Process

1. Fork le repository
2. Créez votre branche (`git checkout -b feature/AmazingTemplate`)
3. Commitez (`git commit -m 'Add amazing template'`)
4. Push (`git push origin feature/AmazingTemplate`)
5. Ouvrez une Pull Request

### Standards

- Templates : XML bien formé
- Documentation : Markdown
- Métriques : Avant/Après obligatoire
- Code examples : Testés

## Questions ?

Ouvrez une Issue ou Discussion sur GitHub.
