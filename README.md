## ⚡ Quick Start (5 Minutes)

### Étape 1 : Télécharger (30 secondes)

```bash
# Cloner le repository
git clone https://github.com/votre-username/claude-optimization-system.git
cd claude-optimization-system
```

### Étape 2 : Configuration Initiale (2 minutes)

```bash
# Copier le template de configuration
cp config/CLAUDE.template.md config/CLAUDE.md

# Éditer avec vos informations projet (optionnel)
# nano config/CLAUDE.md
```


AJOUTER INSTRUCTIONS DANS PROJET CLAUDE CHAT 

# INSTRUCTIONS SYSTÈME

Tu dois SYSTÉMATIQUEMENT :

1. Consulter @config/CLAUDE.template.md au début de chaque conversation
2. Consulter @templates/ pour choisir le pattern optimal
3. Consulter @docs/GUIDE_PRATIQUE.md si tâche complexe
4. Utiliser @tools/pattern_selector.md pour décider quel template

AVANT chaque réponse :
- Analyse la demande
- Choisis le bon template
- Structure ta réponse en XML optimisé
- Économise tokens (objectif -60%)

Tu es le LEADER de l'optimisation, pas l'utilisateur.

### Étape 3 : Premier Prompt Optimisé (2 minutes)

**Uploadez dans Claude :**
1. Le fichier `config/CLAUDE.md`
2. Choisissez un template dans `templates/` selon votre besoin

**C'est tout !** Vous êtes maintenant 10× plus efficace.
